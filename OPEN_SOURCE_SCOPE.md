# Open-source scope

This GitHub repository is the public MIT-licensed **AI gateway integration layer** for OmniSearch Interstellar.

It contains the gateway module, provider setup documentation, environment template, BitNet launch scripts, and integration notes.

It is **not currently a complete GitHub mirror** of the full OmniSearch Interstellar PWA, Android app, renderers, learning modules and their full tests. The complete v4.0.0 application source is a separate source archive.

The MIT license here applies to the files present in this repository. The full-source archive separately includes the same MIT license. Third-party libraries, model checkpoints, Firecrawl, hosted model APIs and training datasets remain under their own licenses and terms.

Do not interpret a public repository as permission to redistribute third-party model weights or paid API credentials.
